Raccourcis clavier
  • / ou Ctrl + K : ouvrir la recherche (le / n'agit pas quand on tape dans un champ)
  • ↑ ↓ puis Entrée : choisir un résultat
  • Échap : fermer la recherche, une bulle d'aide ou le panneau ouvert
